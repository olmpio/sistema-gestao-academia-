Sistema de Gestão de Academia - SmartGym 

## Descrição

O Sistema de Gestão de Academia é um projeto desenvolvido durante a disciplina de Banco de Dados NoSQL, utilizando o MongoDB como sistema de gerenciamento de banco de dados.

A solução tem como finalidade organizar e gerenciar informações relacionadas a uma academia, como alunos, planos, treinos e demais dados necessários para o funcionamento do sistema.

## Objetivo

O objetivo do projeto é desenvolver uma solução de gerenciamento utilizando conceitos de bancos de dados NoSQL, aplicando o MongoDB para armazenamento, consulta, atualização e organização das informações.

O projeto também busca proporcionar à equipe experiência prática com modelagem e manipulação de dados em um banco de dados não relacional.

## Tecnologias utilizadas

* MongoDB
* MongoDB Shell (mongosh)
* Git
* GitHub



### MongoDB

A pasta `mongodb/` contém os scripts utilizados para criação, inserção, consulta e manipulação dos dados do projeto.
